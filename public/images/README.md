# Landing-page image assets

Drop the following file here to enable the hero poster / social-share image:

- `confidentist-hero-poster.webp` — hero poster + Open Graph image.
  Recommended: 1920×1080, WebP, < 200 KB. Focal point centered / slightly high
  (matches `object-position: center 35%`).

If this file is absent the hero still renders (animated brand gradient) with no
broken image and no layout shift.
