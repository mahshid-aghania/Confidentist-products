Tooth Particle Sculpture

The WebGL dental particle sculpture first built for the NDECC hero, kept here so it can be reused elsewhere on the site. Move your cursor over it to disperse the particles — they re-form in about 1–2 seconds.

  • Script: /_assets/particles/tooth-particles.js (WebGL2, no dependencies)
  • Markup: a container <div id="ndHeroVisual" class="nd-hero-visual"> with an optional fallback <svg> inside, placed in a section with class hero
  • Falls back to the static SVG when WebGL2 is unavailable or the visitor prefers reduced motion
  • Adaptive particle count, paused off-screen, disposed on page exit
