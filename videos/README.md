# Landing-page video assets

Drop the cinematic hero video here:

- `confidentist-hero.mp4` — muted, looping, no audio track needed.
  Recommended: 1920×1080, H.264, ~6–12 s loop, < 4–6 MB (compressed).
  Consider a lighter 720p export for mobile if you add a <source media="..."> later.

If this file is absent the hero shows the animated brand gradient fallback and the
pause/play control stays hidden automatically (no broken state).
